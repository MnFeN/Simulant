# 时间轴与实体回归测试

独立 .NET Framework 4.8 / C# 7.3 控制台程序，直接链接时间轴核心、`SimSession`、`EntityRegistry`、`EntityIdentity`、`SimActor`、`SimMovementController`、`SimCastController` 和 `SimOmenRenderer` 的真实源文件，不引用主插件、ACT、游戏进程或 NuGet 包。会话测试用最小替身隔离宿主和逻辑；实体测试以可控对象表观察、内存中的角色替身、CSV 数据和外部 PictoACT 回调替身隔离游戏环境。需要 Windows、.NET Framework 4.8 开发包及 Visual Studio MSBuild。

在仓库根目录的 PowerShell 中执行：

```powershell
$msbuildPath = & "${env:ProgramFiles(x86)}/Microsoft Visual Studio/Installer/vswhere.exe" -latest -products '*' -requires Microsoft.Component.MSBuild -find MSBuild/Current/Bin/MSBuild.exe
& $msbuildPath Simulant.Tests/Simulant.Tests.csproj /p:Configuration=Release /v:minimal /nologo
if ($LASTEXITCODE -ne 0) { throw '测试项目编译失败' }
& ./Simulant.Tests/bin/Release/Simulant.Tests.exe
if ($LASTEXITCODE -ne 0) { throw '回归测试失败' }
```

程序逐项输出 PASS / FAIL，全部通过时退出码为 0。覆盖绝对与相对时间、重复节点、子时间轴与运行快照、同刻顺序、参数验证、较早节点唤醒、堆内取消、错误传播与取消、正在执行节点的取消语义、外部和回调内 Dispose、多线程入队与取消，以及 50,000 节点只由一个非线程池工作线程执行。

会话测试覆盖选项准备失败回滚、初始化节点异常只调用一次停止逻辑、停止时等待初始化退出、停止后重开及重复释放。管理器测试链接真实 `SimEntityManager`，仅替换原生生成器，验证自有实体回收、借用实体只解除关联、停止后拒绝创建，以及回收或日志异常不妨碍其余清理。另覆盖失败资源保留与重试、成功项不重复回收，以及清理完成前拒绝更换调度器或重启会话。

会话并发测试覆盖外部 `Stop/Dispose` 与节点内 `Stop/Dispose/Start` 的六种组合：双方必须按期退出、停止逻辑和实体回收各执行一次，后续节点被取消，节点内重启同一会话明确失败。另验证选项准备或停止回调内的同步重入启动被拒绝。测试场景本身有超时，避免回归死锁拖住整套测试。

未交付本地角色的回收测试验证管理器与生成器状态的衔接：创建抛错且没有返回实体时仍需清理，失败阻止重启，重试成功解除限制，共享生成器不影响另一会话的成功实体，世界重置后不再清理旧记录。这里的原生生成器仍为替身，不证明真实内存读取和原生删除调用成功。

实体测试覆盖同一生命周期的包装复用、并发查询、消失与槽位复用、地址指纹变化、显式失效后不复活、同值重新创建、世界代次切换、拥有相同游戏 ID 的本地对象，以及原生清理失败后的重试只能匹配原生命周期。

移动测试通过真实调度器验证多个角色共享一个待执行更新节点、所有插值写入都在调度线程、运行中更换目标、停止与释放后的取消、失效实体不再写入和无效参数不覆盖原动作。另验证长帧不会越过目标，以及 `SimActor` 在读条清理失败时仍停止移动、重复释放只清理一次、解除关联不销毁底层实体。

取消调度器后再次移动必须明确失败并回滚，不能保留没有更新节点的“正在移动”状态。

网络移动测试验证只发一次 `ActorMove`、低频读取实际位置、到达回调、停止与改目标、本地槽位及无效参数拒绝、超时、停止失败后的责任保留与重试。借用网络角色停止失败时，会话仍保持待清理状态并禁止更换调度器。原生客户端的移动动画与包消费效果仍需实机检查。

读条与预兆测试覆盖替换读条取消旧节点、取消与释放停止后续工作、每次读条使用独立预兆标签、外部不同技能读条与失效实体保护，以及外部回调同步重入后旧逻辑不得清除新读条。延迟预兆在出现时采样位置并使用不受区域设置影响的数字格式；一个清理回调失败后仍清理其他角色。

另验证移除预兆时同步启动新读条、清理控制器或解除角色关联，旧调用不得继续写入；完成预兆移除时由外部技能接管，也不得播放旧技能的完成动画。

P5 分散布局测试链接预设的实际位置算法，验证整组队友都在场内且间距合格；没有合法候选或中途布置失败时，必须明确失败，不能返回未经校验的兜底位置。

阶段应用测试验证退出或替换阶段后旧延迟不再写入天气、BGM 和地图效果；两次应用之间取消也会停止第二次写入。正常延迟保留调用方同步上下文，真实写入错误仍会传播且允许重试。这里隔离了原生环境操作，实际换图与恢复真实位置仍需游戏内验证。

网络实体测试直接链接 NPC / 玩家生成参数、包结构、外观快照解析和职业装备表。验证字段布局、初始状态、UTF-8 名字边界、两种染色的拆分、外观复制与八套已核实的职业装备；缺少套装的职业保留原装备。坐标编码覆盖全部 65536 个编码格的往返、超大坐标截断和非有限输入拒绝。

网络管理器测试以生成器替身隔离原生生成、就绪检查和取消，验证 NPC 与玩家共用一个就绪轮询节点、等待期间取消、重复清理、超时和首个回调异常后的整批回收。这些测试不执行真实生成器或向游戏发送包，不能据此确认当前客户端的原生偏移或角色可见、可选中状态；实机入口及观察步骤见 [实体测试](../docs/EntityTests.md)。

防火墙测试链接真实 `FirewallService`，用内存、地址解析和日志替身注入短写、分配或释放失败，验证回滚、清理重试、仅剩代码洞时的状态及旧内存实例归属。这些测试不执行补丁机器码，也不能证明实际客户端版本、函数入口或网络拦截效果正确。

同步测试使用有超时的事件屏障，不要求精确毫秒调度。耗时和线程池可用线程差值仅用于观察，不作为跨机器性能门槛。这里验证调度、实体身份和模拟行为的协调；原生字段偏移、坐标转换、实际实体释放、读条特效、ACT UI 和游戏画面效果仍需在实际插件环境验证。

## 插件 DLL 故障注入

`Native` 目录直接测试构建后的真实插件 DLL，替换 PostNamazu 的内存读写与原生调用边界，卸载测试另构造离线宿主。它与上面的独立测试程序分开运行，需要主插件本身能够构建；不会启动或连接 ACT、游戏进程。

在仓库根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./Simulant.Tests/Run-NativeTests.ps1
```

脚本构建插件，再编译并分别运行三组 x64 测试；失败时返回非零退出码。

- 创建失败组覆盖 23 项：初始化或读取失败、首次回滚失败、重复清理、实例归属变化、已知冲突禁止重新认领，以及世界重置不访问旧地址。
- ID 分配组覆盖 17 项：从客户端同前缀的最大残留编号续增、玩家和非玩家区间隔离、回收后不倒退、区间用尽拒绝分配，以及隐藏 EObj、待完成网络请求、失败创建、扫描失败无原生副作用、可选角色表和重复指针读取去重。
- 卸载组覆盖 9 项：通过真实 `PluginMain.DeInitPlugin` 停止预设与调试、清理实体、返回原地图和位置、恢复 BGM，最后关闭防火墙；进入模拟中途失败也必须先返回。另向实体回收、地图加载、区域设置、位置恢复、BGM 恢复、收包恢复和代码洞释放注入失败，验证保留宿主及清理记录，后续禁用可重试完成。

这些检查运行真实生成器、实体目录、卸载调用链和 PostNamazu 包装代码，但使用模拟内存和函数结果；不能据此确认国服客户端的偏移、原生函数行为或游戏画面。
