# 实体实机检查

离线测试验证调度、身份和资源生命周期，不能验证客户端包消费、模型动画或原生 UI。本页用于修改相关功能后的游戏内回归；离线入口见 [测试项目说明](../Simulant.Tests/README.md)。

## 入口

完成插件初始化和游戏数据加载，进入旅馆后启用防火墙，再选择“菜单 → 调试功能 → 调试”。留出足够的平坦空地，避免场景遮挡影响观察。

| 入口 | 代码 | 检查内容 |
| --- | --- | --- |
| 普通点击“调试” | `Simulant/Test.NetworkEntity.cs` | 网络 NPC 生成、可选中、移动、读条、删除与重新生成 |
| 按住 Shift 点击“调试” | `Simulant/Test.EntityBehavior.cs` | 本地备用实体的移动、取消与行为衔接 |
| 右键“调试” → 网络玩家测试 | `Simulant/Test.NetworkPlayer.cs` | 职业装备、复制外观、移动与回收 |
| 右键“调试” → 小队列表测试 | `Simulant/Test.Party.cs` | 原生八人小队、血蓝、状态与仇恨 |

再次点击“调试”停止当前测试。手动生成的实体可从“添加实体”的右键菜单选择“清理调试与手动生成实体”。

## 画面检查

- NPC 默认可选中；关闭、重新开启可选中状态后，点击与目标圈一致。
- 移动连续，模型与目标圈朝向一致；不要只看逻辑坐标日志。
- 读条、预兆、结束动画按顺序出现。取消读条后不再出现旧预兆或旧结算。
- 网络玩家显示预期职业与装备；没有预设装备时应正确使用来源角色外观。
- 小队血条随血量变化，状态图标与时长更新；选中测试 Boss 后显示仇恨。状态变化不能仅以实体内存值判断成功。
- 正常结束后无残留实体或预兆；重新运行使用新的实体身份。

## 中断与生命周期

分别在生成尚未就绪、移动途中、读条途中停止，确认后续节点不再执行。若有回收错误，检查日志并重试清理，避免将“停止调度”误认为“原生资源已回收”。

另外检查关闭防火墙、切换区域、游戏掉线和禁用插件：应停止模拟、恢复可恢复的玩家状态，并退出网络隔离。世界或玩家身份已经变化时，不应把旧快照写入新实体；实体、标点清理错误不能使网络一直保持拦截。
