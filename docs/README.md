# 开发文档

这里保留面向项目维护者的使用说明和接口约定。

- [机制时间轴](Timeline.md)：编写预设、节点组合、机制判定与取消。
- [实体与模拟角色](Entities.md)：职责边界、读条、移动、状态与生命周期。
- [网络角色生成](NetworkEntities.md)：生成参数、小队与场地绑定。
- [实体实机检查](EntityTests.md)：客户端画面与生命周期回归步骤。
- [回放读取工具](Replay.md)：离线导出、格式与版本识别边界。

临时触发器、个人回放统计、调查过程、待验证方案和本地 skill 放在根目录 `.local/`，由 Git 忽略，不作为公开文档的依赖。值得长期保留的结论整理为可复用说明后再纳入本目录，不直接追加会话记录。
