# 本地文件导入实施计划

玩家在插件内选择本地 JSON。导入成功后，内容出现在已有的地图和阶段选择器中。发布新版插件时交付读取能力，之后作者可以单独分享描述文件。首版建议支持场地预览和固定时间读条，把绝神兵的一个可核对片段作为新副本的验收样本。[现行格式与开放接口](encounter-format.md)

| 顺序 | 改动 | 完成条件 |
| --- | --- | --- |
| 1. 定稿格式和校验 | 根据 O8S 示例确定 v1 契约，提供与插件校验一致的 JSON Schema；将字段检查、角色引用检查和本机资源查找分开。 | 示例及删去角色和时间轴后的预览版均通过。未知版本、拼错角色、无效技能分别给出可定位的错误。结构检查可以脱离 ACT 运行。 |
| 2. 导入、保存与发现 | 在地图/阶段选择区域增加“导入描述文件”。校验成功后把内容保存到 ACT 配置区下的专用目录；地图筛选和阶段下拉框都从同一份已导入内容列表读取。 | 取消选择没有副作用。移动原文件并重启 ACT 后仍能找到阶段。仅在外部文件中定义的区域可以通过“仅显示含预设区域”找到，纯场地条目可以加载，开始按钮保持禁用。 |
| 3. 接入模拟会话 | 用一个插件内置的通用预设解释 `actors` 和 `cast`。沿用已有的启动条件、时间轴、读条和停止清理。 | O8S 示例只生成一个本体，就绪 3 秒后施放示例技能。在这 3 秒内按“停止”可取消读条节点并清理本体；随即重开只执行新一轮时间轴。内置“异三角”仍可独立选择和运行。 |
| 4. 用绝神兵验证 | 从目标客户端核对绝神兵的区域行号，先导入一个场地预览。再从同版本回放或实测记录选取一个固定读条，核对敌人、位置、技能和相对于就绪时刻的时间，单独制作练习文件。 | 插件安装后只分发 JSON，另一位玩家即可找到该地图、加载阶段并复现选定读条。验收记录写明客户端版本、数据出处和实际覆盖的片段。 |

## 两处容易漏掉的接入细节

- **保存与更新。** 文件内容用稳定的外部 ID 识别，显示名和源文件路径都允许更改。重复导入相同内容只保留一项；同 ID 内容有变时显示将替换的条目，确认后原子替换。校验或写盘失败保留旧版本。当前预设选择和选项持久化使用 C# 类型全名，外部内容应使用独立键，如 `local:example.o8s.trine-opening`，内置预设继续使用原键。[选择恢复](../Simulant/UI/SimulantUI.Territory.cs) · [选项读取](../Simulant/UI/PresetControl.cs) · [选项保存](../Simulant/Core/PluginHost.cs)
- **刷新与会话。** 当前阶段列表重建时会清空预设控件，而控件会停止当前会话。首版可在模拟运行期间禁用导入；结束后再导入并刷新。加载省略 `environment` 的文件时，复用 `PhaseData.TerritoryDefaults` 的默认环境读取路径；当前代码通过这一实例识别“自动读取”，新建一个全零阶段会改变结果。[预设控件](../Simulant/UI/PresetControl.cs) · [阶段环境应用](../Simulant/Core/Zone/ZoneService.Phase.cs)

## 绝神兵试点与复验

首版用 O8S 异三角和绝神兵开场螺旋气流打通本地导入。迦楼罗练习沿用原文件 ID，升级到 v2 后覆盖完整 P1。区域号 777、迦楼罗基础编号 8722、名字编号 1644 和螺旋气流编号 11091 已与本机游戏表核对。天气、攻略选择、固定分工与游戏内验收操作见阶段说明。[迦楼罗练习](uwu-garuda.md) · [BossMod 技能编号](https://github.com/awgil/ffxiv_bossmod/blob/02a16b4425ceed2b63994468da406adddefcd57b/BossMod.Ultimate/Stormblood/Ultimate/UWU/UWUEnums.cs)

在仓库根目录运行 `dotnet run --project tools/EncounterChecks -c Release -- "C:/最终幻想XIV"`，也可以换成本机游戏目录。检查程序使用插件导入器读入三份示例，验证同 ID 升级、错误回滚、重启恢复，以及完整 P1 节点顺序、八职能示范点、读条时长和同一施法者的读条冲突。它还在实际调度器中观察 O8S 的 3 秒读条和迦楼罗的 6.3 秒读条并验证停止取消。[检查程序](../tools/EncounterChecks/Program.cs)

客户端画面与队友动作需要进游戏观察。先加载风场，再分别用八人和单人模式开始练习，途中停止并重新开始，检查旧敌人、队友、风罩和状态是否清理。O8S 的 v1 示例仍可用于复验原来的单次读条。
